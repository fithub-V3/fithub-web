# Features

A running log of features: ideas, plans, and progress for fithub-web.

## How to use this doc

- Add new ideas to **Backlog** as soon as they come up, even half-formed.
- Move a row to **Planned** once it's well-defined enough to build.
- Move to **In Progress** when you start work, **Done** when it ships.
- Keep entries short. Link to issues/PRs/branches instead of duplicating detail.
